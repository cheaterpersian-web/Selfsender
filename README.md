## سرویس زمان‌بندی ارسال پیام تلگرام (CLI)

این ابزار با استفاده از Telethon و APScheduler به شما اجازه می‌دهد:

- ورود به اکانت تلگرام (ذخیره‌ی نشست روی دیسک)
- مشاهده و انتخاب گروه‌ها/سوپرگروه‌ها
- زمان‌بندی ارسال پیام (تک‌مرتبه یا تکرارشونده)

### پیش‌نیازها

- Python 3.9+ نصب باشد.

### نصب

```bash
python3 -m venv .venv && ./.venv/bin/pip install --upgrade pip && ./.venv/bin/pip install -r requirements.txt
```

### اجرا

```bash
./.venv/bin/python main.py
```

در اولین اجرا از شما `API ID` و `API HASH` (از سایت `https://my.telegram.org`) و همچنین شماره موبایل خواسته می‌شود. سپس کد ورود (و در صورت فعال بودن، پسورد 2FA) را وارد می‌کنید. بعد از آن لیست گروه‌ها نمایش داده می‌شود تا انتخاب کنید و پیام و زمان‌بندی را تعیین نمایید.

نکته: تا زمانی که برنامه باز است، زمان‌بندی‌ها اجرا می‌شوند. برای اجرا در پس‌زمینه از ابزارهایی مانند `tmux`, `screen`, یا `systemd` استفاده کنید.
